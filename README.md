# Controle de Compras em Java

Projeto desenvolvido com foco em prática de Programação Orientada a Objetos (POO) em Java.

## 🚀 Funcionalidades
- Cadastro de compras via terminal
- Controle de limite de cartão
- Validação de saldo disponível
- Armazenamento de compras em lista
- Ordenação das compras por valor
- Exibição detalhada das compras realizadas

## 🧠 Conceitos aplicados
- Classes e objetos
- Encapsulamento
- Listas com ArrayList
- Interface Comparable
- Ordenação com Collections.sort
- Laços de repetição (do-while)
- Entrada de dados com Scanner

## 📌 Objetivo
Praticar lógica de programação e consolidar conceitos fundamentais de Java e POO.
